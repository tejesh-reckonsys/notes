1. **The Pragmatic Programmer: 20th anniversary edition** - General tips on software development
2. **Head First: Design Patterns** - Introduction to some basic design patterns and how they can be used. (Examples are in java, but principles work everywhere)
3. **Effective Python** - Best book on intermediate/expert level python best practices
4. **Designing Data Intensive Applications** - Some internals of how databases work and types of data processing
5. **Building Microservices** - Some patterns related to microservices and advantages & disadvantages compared to monolith.
6. **Monolith to Microservices** - Continuation of above book, short info on how to migrate monolith to microservices.
7. **API Security in Action** - Basics of API security. (examples are in Java)
